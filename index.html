Architecture

How the Air-Gap Works

A four-layer local stack, engineered from the ground up for offline-first operation.

01

Ingest & Embed

Your documents, emails, and records are chunked and embedded using local Hugging Face Transformer models. No external embedding API. Everything stays on-disk.

02

Vector Storage

Embeddings are indexed into a local Milvus instance — an enterprise-grade vector database running entirely on your machine. Query millions of vectors in milliseconds.

03

RAG Retrieval

LangChain orchestrates semantic retrieval — your query fetches the most relevant context from your private data vault before hitting the LLM.

04

Local Inference

Ollama / Llama.cpp runs a quantized 7B LLM at 4-bit precision. Smooth inference on mid-range consumer hardware. Zero network calls. Zero exposure.

agent.py Python 
from langchain.llms import Ollama
from langchain.vectorstores import Milvus
from langchain.embeddings import HuggingFaceEmbeddings
from langchain.chains import RetrievalQA

# All local — no network calls made
llm = Ollama(model="llama3:7b-q4_0", base_url="http://localhost:11434")
embeddings = HuggingFaceEmbeddings(model_name="BAAI/bge-small-en-v1.5")
vectordb = Milvus(embedding_function=embeddings, connection_args={"host": "127.0.0.1"})

# RAG chain — sovereign, private, offline
qa_chain = RetrievalQA.from_chain_type(
    llm=llm,
    retriever=vectordb.as_retriever(search_kwargs={"k": 5}),
    return_source_documents=True
)

result = qa_chain("Summarize Q3 financial exposure in my legal contracts")
# ✓ Answered locally. Zero bytes sent to any external server.
